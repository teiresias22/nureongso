# 국회의원 의정활동 — 집계 규칙

화면과 `/rules` 페이지, `/llms.txt` 가 같은 정의를 말해야 한다. 정의를 바꾸면 셋 다 고친다.

- 대표발의와 공동발의는 따로. 공동발의는 합산하지 않는다.
- 가결률 분모 = 대표발의 전체(계류 포함), 계류 건수를 함께.
- 표결 참여율 = (전체 − 불참) / 전체. 출석률 = 출석 / 회의일수 — 둘은 다른 지표다.
- 회의일수 = 출석+결석+청가+출장+**결석신고서**(빼면 11명이 안 맞는다).
- 정당 다수와 다른 표: 같은 의안, 같은 정당(불참 제외, 3명 이상) 다수와 다른 표. 표결 당시 정당이 없어
  **현재 정당** 기준. 위성정당 이름으로 남은 5명은 `party_line()`/`partyLine` 으로 모당에.
- 정당·지역 묶음(`group_record_stats`) 비율은 사람별 평균이 아니라 합계끼리 나눈다. 국회 항목은 지금 국회의원만.
- 이름 잇기: 동명이인은 한자 → 지역구 → 정당(개명·합당 계보를 펴서) 순. 21대 김병욱 둘은 한자까지 같다.
  못 잇는 줄은 억지로 붙이지 않고 비운다.
- `staff` 는 API 가 현재 명단만 줘서 어제와 달라진 것만 `member_staff` 에 적는다.
- 발의자 명단은 새로·바뀐 법안만 다시 넣는다(25만 행).
