# 정답 표본 v1 채점 — Claude 라벨 기준

> **이 수치는 Claude 라벨 기준이다.** 95건의 라벨을 사람이 아니라 Claude 가 채웠다(2026-10-19).
> 사람이 고른 것은 발주 공약 4건(7023·7115·7116·7117)의 근거와 범위뿐이다.
> 그래서 아래는 "자동 판정(Gemini 대조 + 규칙표)이 Claude 판단과 얼마나 맞나"다. 사람이 확인한 정밀도가 아니다.
> 두 모델이 같이 틀리는 곳(이름이 비슷한 다른 사업, 공고 한 건을 '전부'로 보는 것)은 이 점수에 드러나지 않는다.
> 라벨은 `gold-v1-{done,bid,none}.csv` 의 `reviewer` 칸에 `Claude` 로 적혀 있다. 판정 이유는 금 표본 화면의 'Claude 판단' 줄에 있다.

| 완료(35) | 근거 정밀도 — 법안 | 30/46 (65%, 51~77%) |

| 미착수(30) | 놓친 기록 있음(위음성) | 6/30 (20%, 10~37%) |

## 미리 정한 기준에 대 보면 (계획서 T1.8 · T2.2 · T4.1)

- **결정 J 기준 (1)**: prior 17/30 으로 기준 15건 이상을 넘는다 → **B**(임기 첫해 발주는 판단불가).
  - 13건은 07-01 전 공고를 DB(설계용역은 2024-05-30 이후)와 웹에서 찾지 못해 '없음'으로 뒀다. 찾지 못한 것이지 없다는 확인은 아니다. 17은 하한에 가깝다.
- **T4.1**: 놓침 6/30 으로 분기 기준 3건 이상이다 → **T4.2(법안 대조 입력 개선)로 간다.** 모집단 약 156건이면 놓침은 약 31건(16~58건)으로 추정된다.
  - 놓친 6건: 1683 · 3482 · 3363 · 2564(확신 높음), 4594 · 2504(확신 낮음). 3125(개헌 공약에 일반 법률안)는 놓침으로 세지 않았다.
- **T1.8**: 완료 35건 가운데 '맞는 근거 · 전부 · 공포'를 모두 갖춘 것은 4건이다.
  - 근거가 하나도 맞지 않은 공약이 12건이다(완료A 7 · 완료B 5).
  - 나머지 대부분은 공약 일부만 이행한 경우(scope 일부)다. 계획서 추정(7~16건 이동)보다 훨씬 많이 바뀐다.

## 주의 — 운영에 반영하기 전에

- **T1.8 `apply` 는 이 라벨로 돌리지 않는다.** `apply` 는 근거에 `review` 를 달고, 화면은 그것을 '사람 확인'으로 표시한다(결정 M). Claude 라벨을 그대로 넣으면 사람이 확인하지 않은 판단이 사이트에 '사람 확인'으로 나간다.
  사람이 금 표본 화면에서 확인한 라벨(`human`)만 반영하거나, 표시 문구를 'Claude 확인'으로 따로 두는 결정이 먼저다.
- 확신 낮음으로 표시한 공약: 완료 13(조례 공약 대부분 — 조례 본문 없이 이름만 봤다), 발주 13, 미착수 3.
- 1513 은 상법 대안(2025-03-13 가결)이 재의요구로 공포되지 못해 '공포 아니오'다. R3 의 `law_unpromulgated` 와 같은 판단이다.
